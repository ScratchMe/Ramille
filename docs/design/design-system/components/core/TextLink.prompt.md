Toute action textuelle (Retour, « Je ne sais pas », « Changer d’avis », « Modifier mes réponses ») : un TextLink, jamais un span cliquable.

```jsx
<TextLink label="Modifier mes réponses" type="small" themeColor="textTertiary" align="center" />
<TextLink label="Changer d’avis" type="small" themeColor="textTertiary" underline />
```

Lien d’action secondaire accent : `type="linkPrimary"` (14/30/600 accentText). Underline uniquement sur les liens de carte du plan.
