Champ des écrans de connexion. La validation est un `helperText` neutre sous le champ, jamais une couleur d’alerte.

```jsx
<TextField label="Mot de passe" value="••••" type="password" rightActionLabel="Afficher" helperText="Le mot de passe doit contenir au moins 8 caractères." />
```

Bordure accent dès qu’il y a du contenu ou une action ; sinon transparente.
