S’insère en enfant d’ActionCard. L’intention est obligatoire : jours (puces 14) ou échéance fermée (puces outline 16), jamais de saisie libre.

```jsx
<ActionCard titre="…" gainKg={184}><ActionCommitment kind="days" state="picking" days={[1,3]} /></ActionCard>
```

Aucune notion d’échec : « Changer d’avis » libère sans rien compter.
