La mascotte. Cinq expressions, on n’en ajoute pas. Jamais à côté d’un chiffre lourd (total, kilos d’une action, cap). Masquée aux lecteurs d’écran.

```jsx
<Mascot mood="happy" size={44} />
<Mascot mood="calm" size={28} animated={false} />  // en-tête du questionnaire
```

`thinking` uniquement pour le calcul du bilan ; `resting` pour les périodes calmes du suivi. La couleur vient des jetons : la mascotte existe donc en thème sombre sans retouche.
