Le bilan **précédent**, sur les mêmes axes que celui d'aujourd'hui : une barre en contour, jamais pleine.

```jsx
<BarreContour percent={72} hauteur={10} />
```

**Le contour est le passé, le plein est le présent** : une seconde barre pleine, même atténuée, se lirait comme un second résultat. Contour `accentMuted` de 1,5 px, **sans rail** — un rail gris derrière un contour ferait trois épaisseurs pour une seule information.

Deux hauteurs dans le produit : 10 dans l'écart par poste du suivi (six barres à lire d'un coup), 14 sur la restitution d'un re-bilan (une par repère). Masquée au lecteur d'écran : la ligne au-dessus porte les deux valeurs.
