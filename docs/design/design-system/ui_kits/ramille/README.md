# Kit d'écrans — Ramille

Six écrans cliquables recomposés avec les composants du design system : onboarding 1, étape B1.4 du bilan (avec motorisation), restitution, Plan (point + engagement interactif), Suivi, Toi. Bascule thème sombre sur les onglets.

Source des valeurs : `src/app/*`, `src/components/*` du dépôt ScratchMe/Ramille. Les chiffres sont ceux des maquettes, à confirmer côté produit : 3,4 t, 2,1 t, 2,8 t et un cap de 420 kg sur la restitution, 184 kg sur le plan. La restitution, recomposée le 01/10/2026 sur l'écran réel (`v1-33` R-12), ne montre plus le repère 0,6 t au-dessus de la moyenne.

Le catalogue des 38 écrans V1 qui vivait ici (`Catalogue - 38 ecrans.dc.html`, arrivé avec le canvas `v1-14` le 11/09/2026) a été retiré le 27/09/2026, sur décision de la personne qui pilote : jamais mis à jour, il montrait des écrans à mot de passe, un « Check-in manqué » qui nomme une période sans réponse, et l'ancien nom du produit. La vérité des écrans, ce sont les fiches du kit et le produit ; le handoff d'origine reste daté dans `docs/design/` (`docs/architecture/v1-29-challenge-du-design-system.md` §5).
