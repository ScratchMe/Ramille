# Kit d'écrans — Ramille

Six écrans cliquables recomposés avec les composants du design system : onboarding 1, étape B1.4 du bilan (avec motorisation), restitution, Plan (point + engagement interactif), Suivi, Toi. Bascule thème sombre sur les onglets.

Source des valeurs : `src/app/*`, `src/components/*` du dépôt ScratchMe/Ramille. Les chiffres (3,4 t, 2,8 t, 0,6 t, 184 kg) sont ceux des maquettes, à confirmer côté produit.

`Catalogue - 38 ecrans.dc.html` est le catalogue complet des écrans V1 (design de référence, styles inline, 375 × 812), livré avec `support.js`.
